⚡ Functions

What are Functions?

A function is a reusable block of code that performs a specific task. Instead of writing the same code multiple times, write it once in a function!

# Without functions (repetitive!) print("Hello Alice!") print("Hello Bob!") print("Hello Charlie!") # With functions (reusable!) def greet(name): print(f"Hello {name}!") greet("Alice") greet("Bob") greet("Charlie")
💡 DRY Principle: Don't Repeat Yourself! Functions help you write code once and use it many times.

Creating Functions

# Basic function def say_hello(): print("Hello World!") say_hello() # Call the function # Function with parameters def greet(name, age): print(f"Hi {name}, you are {age} years old!") greet("Sarah", 15) # Function with return value def add(a, b): result = a + b return result sum = add(5, 3) print(sum) # 8

Default Parameters

# Functions can have default values def greet(name, greeting="Hello"): print(f"{greeting}, {name}!") greet("Alex") # Uses default: Hello, Alex! greet("Alex", "Hi") # Custom: Hi, Alex! greet("Alex", "Hey") # Custom: Hey, Alex! # Multiple defaults def power(base, exponent=2): return base ** exponent print(power(5)) # 25 (5^2, using default) print(power(5, 3)) # 125 (5^3, custom exponent)

Variable Scope

# Global vs Local scope x = 10 # Global variable def my_function(): y = 5 # Local variable (only exists inside function) print(x) # Can access global x print(y) # Can access local y my_function() print(x) # Works! (global) # print(y) # Error! y only exists inside function # Modifying global variables count = 0 def increment(): global count # Declare we're using global variable count += 1 increment() print(count) # 1
⚠️ Scope Rule: Variables created inside a function are LOCAL (only exist inside). Variables outside are GLOBAL (accessible everywhere).

📁 File Handling

Why File Handling?

Files let your programs save data permanently! Without files, all data is lost when the program ends.

Use Cases:
  • 💾 Save game progress
  • 📝 Store user settings
  • 📊 Save data for analysis
  • 📄 Create reports and logs

Reading Files

# Method 1: Basic read file = open("data.txt", "r") # r = read mode content = file.read() print(content) file.close() # MUST close file! # Method 2: Read line by line file = open("data.txt", "r") for line in file: print(line.strip()) # strip() removes \n file.close() # Method 3: Best practice - with statement (auto-closes!) with open("data.txt", "r") as file: content = file.read() print(content) # File automatically closed when 'with' block ends!
💡 Best Practice: Always use with open() — it automatically closes the file, even if errors occur!

Writing Files

# Write mode - creates new file or OVERWRITES existing with open("output.txt", "w") as file: file.write("Hello World!\n") file.write("This is line 2\n") # Append mode - adds to END of file with open("output.txt", "a") as file: file.write("This is appended!\n") # Writing multiple lines at once lines = ["Line 1\n", "Line 2\n", "Line 3\n"] with open("output.txt", "w") as file: file.writelines(lines)

File Modes

"r" - Read
Opens file for reading. Error if file doesn't exist.
"w" - Write
Creates new file or OVERWRITES existing file.
"a" - Append
Adds to end of file. Creates if doesn't exist.
"r+" - Read/Write
Both read and write. File must exist.
⚠️ Warning: "w" mode DELETES all existing content! Use "a" to preserve existing data.

🎯 Object-Oriented Programming

What is OOP?

Object-Oriented Programming (OOP) is a way to organize code by grouping related data and functions together into "objects".

Without OOP
student1_name = "Alice"
student1_age = 15
student1_grade = 90

student2_name = "Bob"
student2_age = 16
student2_grade = 85

Messy and repetitive! 😵
With OOP
class Student:
  # Code here

alice = Student("Alice", 15, 90)
bob = Student("Bob", 16, 85)

Clean and organized! 🎉

Classes and Objects

Class = Blueprint/Template
Object = Actual instance created from the class

# Define a class (blueprint) class Dog: def __init__(self, name, age): self.name = name # Attribute self.age = age # Attribute def bark(self): # Method (function inside class) print(f"{self.name} says Woof!") def get_info(self): return f"{self.name} is {self.age} years old" # Create objects (instances) dog1 = Dog("Max", 3) dog2 = Dog("Buddy", 5) # Use objects dog1.bark() # Max says Woof! dog2.bark() # Buddy says Woof! print(dog1.get_info()) # Max is 3 years old
💡 Think of a class like a cookie cutter (template) and objects like the actual cookies (instances) you make from it!

The __init__ Method

The __init__ method is a constructor — it runs automatically when you create a new object!

class Student: def __init__(self, name, grade): # 'self' refers to the object being created self.name = name # Set object's name self.grade = grade # Set object's grade print(f"New student created: {name}") # When you create an object, __init__ runs automatically student = Student("Sarah", 90) # Prints: New student created: Sarah print(student.name) # Sarah print(student.grade) # 90

Attributes and Methods

class BankAccount: def __init__(self, owner, balance=0): self.owner = owner # Attribute self.balance = balance # Attribute # Method to deposit money def deposit(self, amount): self.balance += amount print(f"Deposited ${amount}. New balance: ${self.balance}") # Method to withdraw money def withdraw(self, amount): if amount > self.balance: print("Insufficient funds!") else: self.balance -= amount print(f"Withdrew ${amount}. New balance: ${self.balance}") # Method to check balance def get_balance(self): return self.balance # Create account account = BankAccount("Alice", 1000) # Use methods account.deposit(500) # Deposited $500. New balance: $1500 account.withdraw(200) # Withdrew $200. New balance: $1300 print(account.get_balance()) # 1300
🔑 Key Difference: Attributes = Data (variables), Methods = Actions (functions)
