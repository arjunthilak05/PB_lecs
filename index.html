⚖️ Comparison Operators

Comparing Values

Before Python can make decisions, it needs to compare things. Comparison operators ask a question and give back True or False — a Boolean answer!

Think of it like asking: "Is 5 greater than 3?" — Python answers True. "Is 10 equal to 7?" — Python answers False.

⚖️ Key Idea: Comparisons ALWAYS return a Boolean — either True or False. These are the building blocks of all decision-making in code!

The 6 Comparison Operators

==
Equal To
"Are they the same?"
5 == 5 → True 5 == 3 → False
!=
Not Equal To
"Are they different?"
5 != 3 → True 5 != 5 → False
>
Greater Than
"Is left bigger?"
10 > 3 → True 3 > 10 → False
<
Less Than
"Is left smaller?"
3 < 10 → True 10 < 3 → False
>=
Greater or Equal
"Is left bigger or same?"
5 >= 5 → True 3 >= 5 → False
<=
Less or Equal
"Is left smaller or same?"
5 <= 5 → True 7 <= 5 → False

== vs = (The #1 Beginner Mistake!)

This is the most common error in Python! Don't mix them up:

=
Assignment
"Put this value INTO the variable"
x = 5 name = "Alex"
==
Comparison
"Check if these are EQUAL"
x == 5 → True name == "Bob" → False
⚠️ Remember: One = means "store this value." Two == means "are these equal?" Using = in an if statement is a bug!

Comparing Different Types

You can compare numbers, strings, and even variables!

age = 13 name = "Alex" print(age == 13) # True print(age > 10) # True print(age != 13) # False print(name == "Alex") # True (case-sensitive!) print(name == "alex") # False (capital A ≠ lowercase a) print("apple" < "banana") # True (alphabetical order!) print("cat" > "bat") # True
True True False True False True True
🔤 String Comparisons: Python compares strings alphabetically (using ASCII/Unicode values). So "apple" < "banana" because 'a' comes before 'b'!

🚦 If Statements

Making Decisions with If

An if statement lets Python make decisions. It checks a condition — if it's True, the indented code runs. If False, Python skips it!

age = 13 if age >= 13: print("You can create a social media account!") print("Welcome aboard!") print("This always runs.")
You can create a social media account! Welcome aboard! This always runs.
🧩 The Syntax Pattern:
if condition: code that runs if True
1. if keyword starts the statement
2. condition — any expression that returns True or False
3. : colon at the end (don't forget this!)
4. indented block — code that runs only when condition is True

Indentation Matters!

Python uses indentation (spaces at the start) to know which code belongs inside the if statement. This is different from most other languages!

✅ Correct Indentation
if score > 50: print("You passed!") print("Great job!") print("Done.")
Lines 2-3 are INSIDE the if (4 spaces). Line 4 is OUTSIDE.
❌ IndentationError!
if score > 50: print("You passed!") print("Great job!")
Line 2 has no indent — Python crashes with IndentationError!
🔑 Rule: Use exactly 4 spaces for indentation (or press Tab). Be consistent — mixing tabs and spaces causes errors!

If with Else

What if the condition is False? Use else to run different code when the condition isn't met!

temperature = 35 if temperature > 30: print("It's hot outside! ☀️") print("Wear light clothes!") else: print("It's nice outside! 🌤️") print("Enjoy the weather!")
It's hot outside! ☀️ Wear light clothes!

🔀 If-Elif-Else

Multiple Conditions with Elif

Sometimes you need more than two paths! elif (short for "else if") lets you check multiple conditions in order. Python checks from top to bottom and runs the FIRST one that's True.

score = 85 if score >= 90: grade = "A" print("Excellent! 🌟") elif score >= 80: grade = "B" print("Great job! 👍") elif score >= 70: grade = "C" print("Not bad! 📚") elif score >= 60: grade = "D" print("Need improvement 📝") else: grade = "F" print("Let's study more! 💪") print("Your grade:", grade)
Great job! 👍 Your grade: B
🔀 Order Matters! Python checks conditions from top to bottom and runs ONLY the first True one. Put the most specific conditions first! Score 85 matches both ≥80 and ≥70, but since ≥80 comes first, that's the one that runs.

The Complete Pattern

if
First condition to check
Required — there must always be an if
elif
"Otherwise, if this is true..."
Optional — use as many as you need (0, 1, 5, 10...)
else
"If NOTHING above was true..."
Optional — the catch-all fallback (no condition needed)
if condition_1: block_1 # runs if condition_1 is True elif condition_2: block_2 # runs if condition_2 is True elif condition_3: block_3 # runs if condition_3 is True else: default_block # runs if ALL conditions are False

age = int(input("Enter your age: ")) if age < 3: price = 0 print("Free entry! 🎉") elif age <= 12: price = 5 print("Child ticket: $5 🎫") elif age <= 17: price = 8 print("Teen ticket: $8 🎫") elif age >= 65: price = 6 print("Senior ticket: $6 🎫") else: price = 12 print("Adult ticket: $12 🎫") print("Total:", "$" + str(price))

Nested If Statements

You can put if statements inside other if statements! This is called nesting.

has_ticket = True age = 15 if has_ticket: print("You have a ticket! ✅") if age >= 18: print("Welcome to the movie! 🎬") else: print("You need a parent for this movie! 👨‍👩‍👧") else: print("Please buy a ticket first! 🎫")
You have a ticket! ✅ You need a parent for this movie! 👨‍👩‍👧
💡 Keep it clean: Avoid nesting more than 2-3 levels deep — it gets hard to read! Use elif or logical operators instead when possible.

🧠 Logical Operators

Combining Conditions

What if you need to check multiple things at once? Logical operators let you combine conditions!

and
Both Must Be True
True and True → True True and False → False False and True → False False and False → False
or
At Least One True
True or True → True True or False → True False or True → True False or False → False
not
Flips the Value
not True → False not False → True

Using Logical Operators in If Statements

age = 15 has_id = True score = 85 # AND — both conditions must be True if age >= 13 and has_id: print("You can register! ✅") # OR — at least one must be True if score >= 90 or age <= 12: print("You get a prize! 🎁") else: print("No prize this time.") # NOT — flip the condition is_raining = False if not is_raining: print("Let's go outside! ☀️") # Combining multiple if age >= 13 and age <= 19: print("You're a teenager! 🎉")
You can register! ✅ No prize this time. Let's go outside! ☀️ You're a teenager! 🎉

Real Example: Login System

username = input("Username: ") password = input("Password: ") if username == "admin" and password == "python123": print("Login successful! Welcome, admin! 🔓") elif username == "admin" and password != "python123": print("Wrong password! ❌") elif username != "admin": print("User not found! 🔍") else: print("Something went wrong.")
How the logic flows:
1. Check: Is username "admin" AND password "python123"? → Login!
2. Check: Is username "admin" AND password wrong? → Wrong password!
3. Check: Is username NOT "admin"? → User not found!
🧠 Pro Tip: You can chain comparisons in Python! Instead of age >= 13 and age <= 19, you can write 13 <= age <= 19 — Python is one of the few languages that supports this!
