🔀 Lecture 8 — If Statements

What are If Statements?

If statements let your program make decisions — "IF this is true, THEN do that!" They're how programs branch and choose different paths.

# Basic if statement age = 18 if age >= 18: print("You can vote!") print("You're an adult!") # Code here runs regardless of the if print("Program continues...") # If-else: Choose between two options password = "secret123" if password == "secret123": print("✅ Access granted!") else: print("❌ Access denied!")
💡 Indentation matters! Code inside the if block MUST be indented (4 spaces or 1 tab)!

⚠️ Indentation is CRITICAL!

Python uses indentation to know what's inside the if block:

# ✅ CORRECT - Code is indented if age >= 18: print("Adult") # Inside if block print("Can vote") # Inside if block print("Done") # Outside if block # ❌ WRONG - Missing indentation if age >= 18: print("Adult") # ERROR! Must be indented # ❌ WRONG - Inconsistent indentation if age >= 18: print("Adult") # 4 spaces print("Vote") # 6 spaces - ERROR!

🔱 Lecture 9 — If-Elif-Else

Multiple Conditions with Elif

When you have MORE than 2 options, use elif (else if):

# If-elif-else structure score = 85 if score >= 90: print("Grade: A") elif score >= 80: print("Grade: B") elif score >= 70: print("Grade: C") elif score >= 60: print("Grade: D") else: print("Grade: F") # Only ONE block runs! # Python checks from top to bottom # Stops at first True condition
💡 Python checks conditions top to bottom and runs ONLY the first True block!

Nested If Statements

You can put if statements INSIDE other if statements:

# Nested conditionals age = 20 has_license = True if age >= 18: print("Old enough to drive") if has_license: print("✅ Can drive!") else: print("❌ Need a license first") else: print("Too young to drive") # Nested structure if age >= 18: if has_license: if has_car: print("Ready to drive!") else: print("Need a car") else: print("Need license") else: print("Too young")

🧠 Lecture 10 — Logical Operators

Combining Conditions

Logical operators combine multiple conditions:

  • and — BOTH conditions must be True
  • or — AT LEAST ONE condition must be True
  • not — Flips True to False (and vice versa)
# AND - Both must be True age = 20 has_license = True if age >= 18 and has_license: print("Can drive!") # Both True → runs # OR - At least one must be True is_weekend = True is_holiday = False if is_weekend or is_holiday: print("No school!") # One True → runs # NOT - Flips the value is_raining = False if not is_raining: print("Go outside!") # not False = True → runs

📋 Lecture 11 — Lists Introduction

What are Lists?

A list is a collection of items stored in order. Think of it like a shopping list or playlist!

# Creating lists fruits = ["apple", "banana", "cherry"] numbers = [10, 20, 30, 40, 50] mixed = ["Alice", 14, True, 3.14] # Empty list empty = [] # Accessing items by index (starts at 0!) print(fruits[0]) # "apple" print(fruits[1]) # "banana" print(fruits[2]) # "cherry" # Negative indexing (from end) print(fruits[-1]) # "cherry" (last) print(fruits[-2]) # "banana" (second to last) # Length of list print(len(fruits)) # 3
💡 Lists start at index 0, not 1! The first item is list[0]!

List Methods

# Starting list scores = [85, 90, 78] # append() - Add to end scores.append(92) # [85, 90, 78, 92] # insert() - Add at specific position scores.insert(0, 95) # [95, 85, 90, 78, 92] # remove() - Remove first matching item scores.remove(78) # [95, 85, 90, 92] # pop() - Remove and return last item last = scores.pop() # Returns 92 # scores is now [95, 85, 90] # pop(index) - Remove at specific position first = scores.pop(0) # Returns 95 # scores is now [85, 90]

🔧 Lecture 12 — List Operations

Slicing Lists

Extract portions of lists using [start:end]:

numbers = [10, 20, 30, 40, 50, 60] # Basic slicing print(numbers[1:4]) # [20, 30, 40] print(numbers[:3]) # [10, 20, 30] (from start) print(numbers[3:]) # [40, 50, 60] (to end) print(numbers[:]) # [10, 20, 30, 40, 50, 60] (copy) # Step slicing print(numbers[::2]) # [10, 30, 50] (every 2nd) print(numbers[1::2]) # [20, 40, 60] (every 2nd from 1) # Reverse print(numbers[::-1]) # [60, 50, 40, 30, 20, 10]

Sorting & Reversing

# Sorting numbers = [40, 10, 30, 20] # sort() - Sorts in place numbers.sort() # [10, 20, 30, 40] # sorted() - Returns new sorted list original = [40, 10, 30] new = sorted(original) # new = [10, 30, 40] # original unchanged! # Reverse order numbers.sort(reverse=True) # [40, 30, 20, 10] # Reversing numbers.reverse() # [10, 20, 30, 40] # or reversed_list = numbers[::-1]

Built-in Functions

scores = [85, 92, 78, 95, 88] # Basic stats print(len(scores)) # 5 print(min(scores)) # 78 print(max(scores)) # 95 print(sum(scores)) # 438 # Calculate average average = sum(scores) / len(scores) print(average) # 87.6 # Check membership print(95 in scores) # True print(100 in scores) # False
