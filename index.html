📋 Lists — Storing Many Items

What is a List?

A list is like a numbered shelf that holds many items in order. Instead of making a separate variable for every item, put them all in ONE list!

❌ Without Lists (3 variables!)
fruit1 = "apple" fruit2 = "banana" fruit3 = "cherry" # Imagine 100 fruits... 😱
✅ With a List (1 variable!)
fruits = ["apple", "banana", "cherry"] # Even 100 items = 1 variable! 🎉
fruits = ["apple", "banana", "cherry", "mango"] scores = [85, 92, 78, 95, 88] mixed = ["Alex", 13, True, 3.14] # Can mix types! empty = [] # Empty list print(fruits) print("Items:", len(fruits))
['apple', 'banana', 'cherry', 'mango'] Items: 4

List Indexing — Finding Items by Position

Every item has a position number called an index. Python starts counting from 0, not 1!

"apple"

"banana"
index 1
"cherry"
index 2
"mango"

fruits = ["apple", "banana", "cherry", "mango"] print(fruits[0]) # First item print(fruits[2]) # Third item print(fruits[-1]) # LAST item (negative = from end!) print(fruits[-2]) # Second from last
apple cherry mango cherry
⚠️ Index 0 Trap: The FIRST item is [0], the SECOND is [1], the THIRD is [2]. It's like floors in a building — Ground Floor is 0! Using an index that doesn't exist gives an IndexError.

Changing Lists — Add, Remove, Update

Lists are mutable — you can change them after creating them!

# Start with a list fruits = ["apple", "banana", "cherry"] # ADD items fruits.append("mango") # Add to END fruits.insert(1, "orange") # Add at index 1 # CHANGE items fruits[0] = "pineapple" # Replace first item # REMOVE items fruits.remove("cherry") # Remove by value last = fruits.pop() # Remove & return LAST item del fruits[0] # Remove by index print(fruits) print("Popped:", last)
['orange', 'banana'] Popped: mango

Slicing — Grabbing Parts of a List

You can grab a chunk of a list using slicing — give a start and end index separated by a colon :

numbers = [10, 20, 30, 40, 50, 60, 70] print(numbers[1:4]) # Index 1 to 3 (4 is NOT included!) print(numbers[:3]) # First 3 items print(numbers[4:]) # From index 4 to end print(numbers[::2]) # Every 2nd item print(numbers[::-1]) # REVERSED!
[20, 30, 40] [10, 20, 30] [50, 60, 70] [10, 30, 50, 70] [70, 60, 50, 40, 30, 20, 10]
✂️ Slicing Rule: list[start:end] includes start but excludes end. Think of it as: "Start here, stop BEFORE there."

🔁 For Loops — Repeat for Each Item

The Problem: Doing the Same Thing Many Times

Imagine you have 5 friends and want to say hello to each one. Without loops:

print("Hello, Alex!") print("Hello, Priya!") print("Hello, Sam!") print("Hello, Riya!") print("Hello, Jordan!") # What if you had 1000 friends? 😰

That's 5 nearly identical lines! A for loop does this in just 2 lines:

friends = ["Alex", "Priya", "Sam", "Riya", "Jordan"] for name in friends: print("Hello,", name, "!")
Hello, Alex ! Hello, Priya ! Hello, Sam ! Hello, Riya ! Hello, Jordan !
🔁 The Magic: The loop automatically goes through EVERY item in the list, one by one, and runs the indented code each time. 5 friends or 5000 — same 2 lines of code!

Let's trace through the loop slowly so you see exactly what happens at each step:

🔄 While Loops — Repeat Until Done

For vs While — What's the Difference?

A for loop says: "Do this for each item in this collection."
A while loop says: "Keep doing this while this condition is True."

🔁 For Loop
"Go through each student
in the class and say hello."
You KNOW how many times
🔄 While Loop
"Keep guessing the password
until you get it right."
You DON'T know how many times

How a While Loop Works

A while loop checks the condition before each round. If True → run the code. If False → stop!

count = 1 while count <= 5: print("Count is:", count) count = count + 1 # VERY IMPORTANT! print("Loop ended!")
🔍 Step-by-Step Trace:
Roundcount valuecount <= 5?What happens
11True ✓Print 1, count→2
22True ✓Print 2, count→3
33True ✓Print 3, count→4
44True ✓Print 4, count→5
55True ✓Print 5, count→6
66False ✗STOP! Exit loop
Count is: 1 Count is: 2 Count is: 3 Count is: 4 Count is: 5 Loop ended!

⚠️ The Infinite Loop Danger!

If you forget to update the variable, the condition NEVER becomes False and the loop runs forever!

❌ INFINITE LOOP (BAD!)
count = 1 while count <= 5: print(count) # Forgot count += 1 !! # count is ALWAYS 1 # 1 <= 5 is ALWAYS True # Runs FOREVER! 💀
✅ CORRECT (stops!)
count = 1 while count <= 5: print(count) count += 1 # ← THIS! # count changes: 1→2→3→4→5→6 # 6 <= 5 is False → STOPS!
⚠️ Golden Rule: Every while loop MUST have something inside that changes the condition toward False. If you forget, press Ctrl+C to force-stop the program!

While Loop Real Examples

# Example 1: Guessing game secret = 7 guess = 0 while guess != secret: guess = int(input("Guess (1-10): ")) if guess < secret: print("Too low! ⬆️") elif guess > secret: print("Too high! ⬇️") print("You got it! 🎉") # Example 2: Countdown countdown = 5 while countdown > 0: print(countdown, "...") countdown -= 1 print("Blast off! 🚀")
5 ... 4 ... 3 ... 2 ... 1 ... Blast off! 🚀

break and continue — Loop Control

break — EXIT the loop now!
for i in range(10): if i == 5: break # STOP at 5! print(i) # Output: 0, 1, 2, 3, 4
Like hitting the emergency stop button 🛑
continue — SKIP this round!
for i in range(6): if i == 3: continue # Skip 3! print(i) # Output: 0, 1, 2, 4, 5
Like saying "nah, next!" and moving on ⏭️
