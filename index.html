⌨️ Part 1 — User Input & Type Conversion

What is User Input?

So far, your programs only show information. But real programs are interactive — they ask the user questions and respond to their answers! In Python, we use the input() function to pause the program and wait for the user to type something.

input("What is your name? ")

The message inside the quotes is called a prompt — it tells the user what to type. The program waits, the user types, presses Enter, and the answer is captured.

💡 input() always returns a string — even if the user types a number like 25. That's very important and we'll fix it with type conversion!

Saving Input to a Variable

To actually use what the user typed, store it in a variable using =:

# Ask the user and save the answer name = input("What is your name? ") city = input("What city are you from? ") print("Hello,", name) print("You are from", city)

If the user types "Arjun" and "Chennai", the output will be:

Hello, Arjun You are from Chennai

⚠️ The Problem: input() Always Returns a String

What if you ask for someone's age and try to do maths with it?

# This will CRASH! age = input("How old are you? ") # user types 14 print(age + 1) # ❌ TypeError: can only concatenate str, not int

Even though the user typed 14, Python stored it as the text "14" (a string), not the number 14 (an integer). You can't add a number to text!

⚠️ Common Mistake: Forgetting to convert input to a number before doing arithmetic. This is one of the most frequent bugs beginners write!

🔄 Type Conversion — Fixing the Problem

Python gives us conversion functions to change one data type into another:

FUNCTION
CONVERTS TO
EXAMPLE
int()
Whole number (integer)
int("14") → 14
float()
Decimal number
float("3.7") → 3.7
str()
Text (string)
str(42) → "42"
bool()
True / False
bool(0) → False
# The RIGHT way — wrap input() with int() age = int(input("How old are you? ")) next_year = age + 1 print("Next year you will be", next_year) # For decimals (like height), use float() height = float(input("Your height in cm? ")) print("Height in metres:", height / 100)
💡 Think of it like currency exchange — int() is like converting your money from one currency to another. The value changes form, but it still represents the same thing.

🔤 Part 2 — String Operations

What is a String?

A string is any sequence of characters — letters, numbers, spaces, symbols — wrapped in quotes. Python treats them as text, not numbers.

greeting = "Hello, World!" name = 'Python' # single OR double quotes both work sentence = "I have 3 cats" # numbers inside strings are text! empty = "" # a string can even be empty

➕ Concatenation — Joining Strings

Use + to join (concatenate) two strings together. Use * to repeat a string:

first = "Hello" last = "World" # Joining with + print(first + " " + last) # Hello World # Repeating with * print("Ha" * 3) # HaHaHa print("-" * 20) # ——————————————————————
⚠️ You can only concatenate string + string. Never try to do "Age: " + 25 — that crashes! You must convert: "Age: " + str(25)

🔤 f-strings — The Modern Way to Mix Text & Variables

Instead of messy concatenation, Python (3.6+) lets you use f-strings — put an f before the quote and then drop variables inside {curly braces}:

name = "Priya" age = 14 score = 97.5 # Old way (messy) print("Hello, my name is " + name + " and I am " + str(age) + " years old.") # f-string way (clean!) print(f"Hello, my name is {name} and I am {age} years old.") print(f"Score: {score:.1f}%") # .1f = 1 decimal place → 97.5% print(f"Next year I'll be {age + 1}") # can do maths inside {}!
💡 f-strings can contain any Python expression inside {} — variables, maths, function calls. They're the professional way to format output.

🔧 String Methods — Built-in Superpowers

Strings come with built-in methods — mini functions that do useful things to text. Call them with a dot: my_string.method()

.upper()
Convert every letter to UPPERCASE "hello".upper() → "HELLO"
.lower()
Convert every letter to lowercase "PYTHON".lower() → "python"
.strip()
Remove whitespace (spaces/tabs) from start and end " hello ".strip() → "hello"
.replace(a, b)
Replace every occurrence of a with b "I like cats".replace("cats", "dogs") → "I like dogs"
.split(sep)
Split a string into a list at every separator "a,b,c".split(",") → ["a", "b", "c"]
.len() → len()
Count total characters (note: use built-in len(), not a method) len("Python") → 6
.startswith()
Returns True if string starts with given text "Hello".startswith("He") → True
.count()
Count how many times a substring appears "banana".count("a") → 3
# Chaining methods together! msg = " Hello, World! " print(msg.strip().lower().replace("hello", "hi")) # → "hi, world!"

🔍 Understanding the Special Three

// Floor Division

Divides but throws away the decimal part — it gives you the whole number quotient only. Think of it as "how many times does it go in without going over?"

10 // 3 → 3 # 3 goes 3 times 7 // 2 → 3 # 2 goes 3 times 9 // 9 → 1

% Modulo (Remainder)

Gives you the leftover after dividing. Super useful for checking if a number is even/odd, or cycling through things.

10 % 3 → 1 # 10 = 3×3 + 1 7 % 2 → 1 # odd! 8 % 2 → 0 # even!

** Exponentiation (Power)

Raises a number to a power. 2 ** 8 means 2 × 2 × 2 × 2 × 2 × 2 × 2 × 2 = 256. Way shorter than writing it out!

2 ** 10 → 1024 # 2 to the power 10 3 ** 3 → 27 # 3 cubed 25 ** 0.5 → 5.0 # square root! (power of 0.5)
💡 Real-world uses: % tells you if a number is even (n % 2 == 0), checks divisibility, and helps with clocks/cycles. // is used for integer division like splitting items into groups.

🔨 Putting It All Together

📐 Part 4 — Order of Operations (PEMDAS)

Why Order Matters

When an expression has multiple operators, Python doesn't just go left to right — it follows a strict priority order. Get this wrong and your calculations will be completely off!

❌ WRONG THINKING
2 + 3 * 4
= (2+3) * 4 ← Don't do this!
= 20 (WRONG)
✅ CORRECT (PEMDAS)
2 + 3 * 4
= 2 + (3*4) ← * before +
= 14 (CORRECT)

The PEMDAS Order

PEMDAS is a mnemonic (memory trick) — each letter stands for one priority level. Higher up = done first:

P
Parentheses
( )
E
Exponents
**
M
Multiplication
*
D
Division
/ // %
A
Addition
+
S
Subtraction
-

When two operators have the same level (like * and /), Python goes left to right.

💡 Memory trick: "Please Excuse My Dear Aunt Sally" — one word for each letter of PEMDAS. Mathematicians and programmers use this worldwide!

📝 Worked Examples — Step by Step

Example 1:  2 + 3 * 4 - 1

1
No parentheses or exponents, so look for × ÷ first → find 3 * 4
2
= 2 + 12 - 1
3
Now left to right for + and - → 2 + 12 = 14, then 14 - 1

Example 2:  (2 + 3) ** 2 / 5

1
Parentheses first → (2 + 3) = 5
2
= 5 ** 2 / 5 → Exponent next = 25
3
= 25 / 5 → Division = 5.0
✓

Example 3:  10 - 2 ** 3 + 4 * (1 + 1)

1
Parentheses → (1 + 1) = 2
2
= 10 - 2 ** 3 + 4 * 2 → Exponent: 2**3 = 8
3
= 10 - 8 + 4 * 2 → Multiply: 4*2 = 8
4
= 10 - 8 + 8 → Left to right: 10-8=2, then 2+8
✓
= 10

🛡️ When in Doubt — Use Parentheses!

Even when you know PEMDAS, adding parentheses makes your code clearer and prevents bugs. This is what professional programmers do:

# Hard to read — relies on you knowing PEMDAS perfectly result = a + b * c ** 2 / d - e # Clear — your intent is obvious to anyone reading it result = a + ((b * (c ** 2)) / d) - e # Real-world example: area of a trapezoid area = ((base1 + base2) * height) / 2
💡 In coding, readable code beats clever code. Extra parentheses cost nothing — use them to make your intentions crystal clear!
