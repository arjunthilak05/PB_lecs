🖨️ Print Statements

Your First Python Program

The print() function displays text on the screen. This is how your program talks to you!

print("Hello, World!") print("I am learning Python!") print("Python is awesome!")
Hello, World! I am learning Python! Python is awesome!
💡 Important: Text must be inside quotation marks (" " or ' '). Python won't print without them!

Printing Multiple Things

You can print multiple items separated by commas. Python adds spaces between them automatically!

print("My name is", "Alex") print("I am", 13, "years old") print("I love", "Python", "and", "AI")
My name is Alex I am 13 years old I love Python and AI
🎯 Notice: Numbers don't need quotes, but text does!

Print with Special Characters

New Line: \n
print("Line 1\nLine 2\nLine 3")
Line 1 Line 2 Line 3
Tab Space: \t
print("Name:\tAlex\nAge:\t13")
Name: Alex Age: 13

📦 Variables & Data Types

What is a Variable?

A variable is like a labeled box that stores information. You can put data in the box and use it later!

name = "Alex" age = 13 height = 5.4 is_student = True print("Name:", name) print("Age:", age) print("Height:", height, "feet") print("Is student?", is_student)
Name: Alex Age: 13 Height: 5.4 feet Is student? True
📦 Variable Rules: No spaces in names, can't start with numbers, use lowercase with underscores (my_variable)

Checking Data Types

Use type() to find out what type of data a variable holds!

name = "Alex" age = 13 height = 5.4 is_student = True print(type(name)) print(type(age)) print(type(height)) print(type(is_student))
<class 'str'> <class 'int'> <class 'float'> <class 'bool'>

Variables Can Change!

You can change a variable's value anytime. The latest value replaces the old one!

score = 80 print("Score:", score) score = 95 # Changed! print("New score:", score) score = score + 5 # Add 5 to current score print("Final score:", score)
Score: 80 New score: 95 Final score: 100

⌨️ User Input & Output

Getting User Input

Use input() to ask the user for information. The program waits for them to type and press Enter!

name = input("What is your name? ") print("Hello,", name, "!") age = input("How old are you? ") print("You are", age, "years old")
Output Example:
What is your name? Alex Hello, Alex ! How old are you? 13 You are 13 years old
⌨️ Important: input() always returns text (string)! Even if you type a number, it's stored as text.

Converting Input to Numbers

To do math with user input, convert it to a number using int() or float()!

# Wrong way - won't work for math! age = input("Enter your age: ") next_year = age + 1 # ERROR! Can't add number to text # Correct way - convert to integer age = int(input("Enter your age: ")) next_year = age + 1 print("Next year you'll be", next_year)
Conversion Functions:
• int() → Converts to whole number (integer)
• float() → Converts to decimal number
• str() → Converts to text (string)

PEMDAS: Order of Operations

When you have multiple operations, Python follows PEMDAS order!

🎯 PEMDAS Order
P
Parentheses ( )
Do these first!
E
Exponents **
Powers and roots
MD
Multiplication & Division * / // %
Left to right
AS
Addition & Subtraction + -
Left to right

PEMDAS Examples

Example 1: Without Parentheses
result = 5 + 3 * 2 print(result)
Step by step:
1. Multiply first: 3 * 2 = 6
2. Then add: 5 + 6 = 11
11
Example 2: With Parentheses
result = (5 + 3) * 2 print(result)
Step by step:
1. Parentheses first: 5 + 3 = 8
2. Then multiply: 8 * 2 = 16
16
Example 3: Complex Expression
result = 10 + 2 ** 3 * 4 - 6 / 2 print(result)
Step by step:
1. Exponent: 2 ** 3 = 8
2. Multiply: 8 * 4 = 32
3. Divide: 6 / 2 = 3.0
4. Add left to right: 10 + 32 = 42
5. Subtract: 42 - 3.0 = 39.0
39.0
💡 Pro Tip: Use parentheses ( ) to make your code clear and control the order of operations!
